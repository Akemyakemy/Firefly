## 线性筛

$O(n)$

```c++
int vis[N],prim[N],cnt=0;

void get_prim(int n){
    for(int i=2;i<=n;i++){
        if(!vis[i]) prim[++cnt]=i;
        for(int j=1;i*prim[j]<=n && j<=cnt;j++){
            vis[i*prim[j]]=1;
            if(i%prim[j]==0) break;
        }
    }
}
```

只需要像上面这样扫描一遍就能找出n以内的所有质数了。
