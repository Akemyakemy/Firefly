## 快速幂

```c++
const int p=998244353;

int qp(int a,int b){//求a的b次方模p的值
    int res=1;
    while(b){
        if(b&1) res=res*a%p;
        a=a*a%p;
        b>>=1;
    }
    return res;
}
```
