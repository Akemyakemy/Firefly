## 分解质因数

根据[唯一分解定理](https://blog.542000.xyz/posts/%E6%95%B0%E8%AE%BA/%E7%AD%9B%E6%B3%95%E6%B1%82%E5%90%84%E7%B1%BB%E5%87%BD%E6%95%B0/)，每个合数都可以唯一分解为质数的乘积。

### 试除法

利用试除法可以分解质因数，时间复杂度为$O(\sqrt{n})$。

```c++
vector<int> factor;
void f(int n){
    if(n<=1) return;
    for(int i=2;i*i<=n;i++){
        if(n%i==0){
            factor.push_back(i);
            while(n%i==0) n/=i;
        }
    }
    if(n>1) factor.push_back(n);
}
```

值得注意的是，如果已经打了一个素数表的话，时间复杂度就会下降到$O(\sqrt{n}/logn)$。

### Pollard-Rho算法

Pollard-Rho算法是一种基于随机数的分解质因数算法，时间复杂度为$O(n^{1/4})$。

#### 生日悖论

原问题描述：假设一年有n天，至少有几个人使得存在两人生日相同的概率为50%？

结论：$1\sim N$ 随机选数，大约选$\sqrt{n}$个数，就有50%左右概率出现两个数模$p$相等。

具体公式为：
$$
P\left( A \right) \text{为所有数模}p\text{不相等的概率}
$$
$$
P\left( A \right) =\prod_{i=0}^{k-1}{\frac{n-i}{n}}\le 0.5
$$
$$
\text{由}1+x\le e^x\text{得到}
$$
$$
P\left( A \right) \le \prod_{i=1}^{k-1}{\exp \left( -\frac{i}{n} \right)}=\exp \left( -\frac{k\left( k-1 \right)}{2n} \right) 
$$
$$
k\ge \frac{1+\sqrt{1+\left( 8\ln 2 \right) n}}{2}
$$
$$
\text{当}n=365\text{时，}k\ge 23
$$

可以类似地计算，随机均匀地取一列生日，首次获得重复生日的人数期望也是$O(\sqrt{n})$的。
$$
E\left( x \right) =\sum_{x=1}^{n+1}{P\left( X\ge x+1 \right)}=\sum_{x=0}^n{\frac{n!}{\left( n-x \right) !n^x}}=\sqrt{\frac{\pi n}{2}}-\frac{1}{3}+o\left( 1 \right)
$$

#### 素性测试

这里将使用[Miller-Rabin素性测试](https://blog.542000.xyz/posts/%E6%95%B0%E8%AE%BA/%E7%B4%A0%E6%80%A7%E6%B5%8B%E8%AF%95/)来检测素数。

```c++
int arr[]={2,325,9375,28178,450775,9780504,1795265022};//1e18范围

bool millerRabin(int n){
    if(n<3 || !(n&1)) return n==2;
    if(n%3==0) return n==3;
    int u=n-1,,t=0;
    while(!(u&1)) u>>=1,t++;
    
    for(int i:arr){
        if(i>=n) break;
        int v=quickPow(i,u,n);
        if(v==1) continue;
        int s;
        for(s=0;s<t;s++){
            if(v==n-1) break;
            v=(long long) v*v%n;
        }
        if(s==t) return 0;
    }
    return 1;
}
```

#### 分解思路

设$n$是合数，$p是n的一个未知真因子$。

$如果能找到一对不相等的x，y，模p相等。$

则：
$$
p\ |\ |x-y|\Longrightarrow gcd\left( |x-y|,n \right) =d>1
$$
此时$d$就是$n$的一个非平凡因子。（非1非n）

#### 迭代函数

$$
f\left( x \right) =x^2+c\left( mod\ p \right) \left( c\ne 0,-2 \right)
$$

$模p的余数最多有p种，根据抽屉原理，迭代p+1次后一定出现重复值$。（环）

如果出现$gcd(|x-y|,n)\equiv n$则分解失败需要修改c的数值。

生成随机数：

```c++
mt19937 rng(chrono::steady_clock::now().time_since_epoch().count());//mt19937_64
uniform_int_distribution<int> dist(0,n-1);//设定范围,若不设定范围则为0~2^64-1
int c=dist(rng);//int c=rng();
```

##### Floy判环

龟兔赛跑，A每次跑两步，B每次跑一步，经过一段时间一定会相遇。

```c++
int pollardRho(int n){
    if(n==4) return 2;//因为一开始跳了2步，所以需要特判一下4
    int c=dist(rng)+1;
    int t=f(0,c,n),r=f(f(0,c,n),c,n);
    while(t^r){
        int d=gcd(abs(t-r),n);
        if(d>1) return d;
        t=f(t,c,n);
        r=f(f(r,c,n),c,n);
    }
    return n;
}
```

##### Brent判环

常数优化，减少了24%的时间。

$从k=1开始递增k，在第k轮，让A等在原地，B移动2^k步，如果图中遇到了A，则说明已经有环，让A瞬移到B的未知，然后继续下一轮。$

##### 倍增优化

使用乘法累计来减少$gcd$的次数。

原理：如果$gcd(a,N)>1,则gcd(ab,N)>1对于任意b>0成立。$

计算$gcd\left( \prod{|x_i-x_j|}mod\ n,n \right) >1$即可。没$k=128$对计算一次$gcd$ 。

```c++
int pollardRho(int n){
    int t=0;
    int c=dist(rng)+1;
    int s=t;
    int step=0,goal=1;
    int val=1;
    for(goal=1;;goal<<=1,s=t,val=1){
        for(step=1;step<=goal;++step){
            t=f(t,c,n);
            val=val*abs(t-s)%n;
            if(!val) return n;
            if(step%127==0){
                int d=gcd(val,n);
                if(d>1) return d;
            }
        }
        int d=gcd(val,n);
        if(d>1) return d;
    }
}
```

#### 具体实现

[求一个数的最大素因子。](https://www.luogu.com.cn/problem/P4718)

$O\left( n^{\frac{1}{4}} \right) $,1e18最多不超过2e5次

```c++
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'

inline int qpow(int a,int b,int mod){
	int res=1;
	while(b){
		if(b&1) res=res*a%mod;
		a=a*a%mod;
		b>>=1;
	}
	return res;
}

int arr[]={2,325,9375,28178,450775,9780504,1795265022};
inline bool millerRabin(int n){
	if(n<3 || !(n&1)) return n==2;
	if(n%3==0) return n==3;
	int u=n-1,t=0;
	while(!(u&1)) u>>=1,t++;
	
	for(int i:arr){
		if(i>=n) break;
		int v=qpow(i,u,n);
		if(v==1) continue;
		int s;
		for(s=0;s<t;s++){
			if(v==n-1) break;
			v=v*v%n;
		}
		if(s==t) return 0;
	}
	return 1;
}

inline int gcd(int a,int b){
	return b?gcd(b,a%b):a;
}
inline int f(int x,int c,int n){
	return (x*x+c)%n;
}
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
inline int pollardRho(int n){
	int s=0,t=0;
	int c=rng()%(n-1)+1;
	int step=0,goal=1;
	int val=1;
	for(goal=1;;goal<<=1,s=t,val=1){
		for(step=1;step<=goal;step++){
			t=f(t,c,n);
			val=val*abs(t-s)%n;
			if(!val) return n;
			if(step%127==0){
				int d=gcd(val,n);
				if(d>1) return d;
			}
		}
		int d=gcd(val,n);
		if(d>1) return d;
	}
}

int maf;
inline void fac(int n){//递归分解质因子，更新全局最大质因子
	if(n<=maf || n<2) return;//已有更大因子或<2
	if(millerRabin(n)){
		maf=max(maf,n);
		return;
	}
	
	int p=n;
	while(p>=n) p=pollardRho(n);//得到一个因子p
	while((n%p)==0) n/=p;//出干净，递归求其他因子
	fac(n),fac(p);//fac(n)递归，fac(p)更新maf
}

inline void solve(){
	int n;cin>>n;
	maf=0;
	fac(n);
	if(maf==n) cout<<"Prime\n";
	else cout<<maf<<endl;
}

signed main(){
	cin.tie(nullptr)->sync_with_stdio(false);
	int t;cin>>t;
	while(t--) solve();
	return 0;
}
```
