## 最大公因数

欧几里得算法（辗转相除法）

```c++
int gcd(int a,int b){
    return !b?a:gcd(b,a%b);
}
```

## 最小公倍数

```c++
int lcm(int a,int b){
    return a*b/gcd(a,b);
}
```

## 逆元

逆元的定义：当$a×b\equiv1(mod\ p),p$为质数时，b与a互为模p的逆元。

费马小定理：当$a \perp p$时，$a^{p-1}\equiv1(mod\ p)$.

所以求a的逆元即求$a^{p-2}(mod\ p)$.

```c++
const int p=998244353;

int inv(int a){
    return quickPow(a,p-2)%p;
}
```
