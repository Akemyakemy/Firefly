# 筛法求各类函数

这里将会介绍各种数论函数，并通过线性筛的方式快速求出。

至于求出来有什么用，你先别管。😅

## 唯一分解定理

定理：所有数都可被唯一地分解成其质因数的乘积形式。
$$
n = p_1^{\alpha_1} p_2^{\alpha_2} \cdots p_k^{\alpha_k} = \prod_{i=1}^k p_i^{\alpha_i}
$$

## 欧拉函数

**定义**：$1 \sim n$ 中与$n$互质的数的个数。

**性质**：
$$
\begin{array}{ll}
1.\text{若}p\text{是质数，则}\varphi \left( p \right) =p-1 \\
2.\text{若}p\text{是质数，则}\varphi \left( p^k \right) =\left( p-1 \right) p^{k-1} \\
3.\text{积性函数：若}\gcd\left( m,n \right) =1,\text{则}\varphi \left( mn \right) =\varphi \left( m \right) \varphi \left( n \right)
\end{array}
$$
**计算公式**：
$$
\begin{aligned}
\text{由唯一分解定理 } n &= \prod_{i=1}^s p_i^{\alpha_i} = p_1^{\alpha_1}p_2^{\alpha_2}\cdots p_s^{\alpha_s}, \\
\varphi(n) &= \prod_{i=1}^s \varphi(p_i^{\alpha_i}) \\
&= \prod_{i=1}^s p_i^{\alpha_i-1}(p_i - 1) \\
&= \prod_{i=1}^s p_i^{\alpha_i}\left(1 - \frac{1}{p_i}\right) \\
&= \prod_{i=1}^s p_i^{\alpha_i} \times \prod_{i=1}^s\left(1 - \frac{1}{p_i}\right) \\
&= n \times \prod_{i=1}^s \frac{p_i - 1}{p_i} \\
&= n \times \frac{p_1 - 1}{p_1} \times \frac{p_2 - 1}{p_2} \times \cdots \times \frac{p_s - 1}{p_s}
\end{aligned}
$$
欧拉函数仅由 $n$ 和质因子决定，与次数无关。

### 筛法求欧拉函数

1. 若$i$是质数，$phi[i]=i-1$.

2. 每个合数都会被**最小的因子**筛掉（因为线性筛从小质数开始筛），$p_j$是$m$的最小质因子，则$m$被$m=i*p_j$筛掉。

3. 若$i$能被$p_j$整除，则$i$包含了$m$所有的质因子，则
   $$
   \varphi \left( m \right) =p_j\times \varphi \left( i \right)
   $$

4. 若$i$能被$p_j$整除，则$i$和$p_j$是互质的，则

5. $$
   \varphi \left( m \right) =\varphi \left( p_j\times i \right) =\varphi \left( p_j \right) \times \varphi \left( i \right) =\left( p_j-1 \right) \times \varphi \left( i \right)
   $$

```c++
const int N=1e5+9;
int p[N],vis[N],cnt;
int phi[N];

void get_phi(int n){
    phi[1]=1;
    for(int i=2;i<=n;i++){
        if(!vis[i]){//i是质数
            p[cnt++]=i;
            phi[i]=i-1;
        }
        for(int j=0;i*p[j]<=n;j++){
            int m=i*p[j];
            vis[m]=1;
            if(i%p[j]==0){
                phi[m]=p[j]*phi[i];
                break;
            }else phi[m]=(p[j]-1)*phi[i];
        }
    }
}
```

## 约数

约数即可以将该数整除的数。

### 筛法求约数个数

**约数个数定理**：
$$
\begin{aligned}
&\text{若 } n = \prod_{i=1}^s p_i^{\alpha_i}, \text{ 则 } d(n) = \prod_{i=1}^s (\alpha_i + 1)。 \\
\\
&\text{证明：} p_i^{\alpha_i} \text{ 的约数有 } p_i^0, p_i^1, \cdots, p_i^{\alpha_i} \text{ 共}(\alpha_i + 1)\text{个}, \\
&\quad \text{根据乘法原理，} d(n) = \prod_{i=1}^s (\alpha_i + 1)。
\end{aligned}
$$
**公式**：
$$
\begin{aligned}
&\text{若 } i \text{ 是质数，} a[i] = 1, d[i] = 2。 \\
&\text{在线性筛中，每个合数 } m \text{ 都是被最小的质因子筛掉的。} \\
&\text{设 } p_j \text{ 是 } m \text{ 的最小质因子，则 } m \text{ 通过 } m = p_j \times i \text{ 筛掉。} \\
&(1) \text{ 若 } i \text{ 能被 } p_j \text{ 整除，则 } p_j \text{ 一定是 } i \text{ 的最小质因子。} \\
&\quad a[m] = a[i] + 1; \\
&\quad d[m]=d[i]/a[m] \times (a[m]+1); \\
&(2) \text{ 若 } i \text{ 不能被 } p_j \text{ 整除，则 } i \text{ 不包含质因子 } p_j。 \\
&\quad a[m] = 1, d[m] = d[i] \times (1 + 1)
\end{aligned}
$$

```c++
const int N=1e5+9;
int p[N],vis[N],cnt;
int a[N];//a[i]记录i的最小质因子的次数
int d[N];//记录i的约数个数
void get_d(int n){
    d[1]=1;
    for(int i=2;i<=n;i++){
        if(!vis[i]){
            p[++cnt]=i;
            a[i]=1;d[i]=2;
        }
        for(int j=1;i*p[j]<=n;j++){
            int m=i*p[j];
            vis[m]=1;
            if(i%p[j]==0){
                a[m]=a[i]+1;
                d[m]=d[i]/a[m]*(a[m]+1);//a[m]=a[i]+1
                break;
            }else{
                a[m]=1;
                d[m]=d[i]*2;//i的所有约数能与p[j]组合一次成为m的一种约数
            }
        }
    }
}
```

### 筛法求约数和

**约数和定理**：
$$
\begin{aligned}
&\text{若 } n = \prod_{i=1}^s p_i^{\alpha_i}, \text{ 则 } f(n) = \prod_{i=1}^s \sum_{j=0}^{\alpha_i} p_i^j \\
\\
&\text{证明：} p_i^{\alpha_i} \text{ 的约数有 } p_i^0, p_i^1, \cdots, p_i^{\alpha_i} \text{ 共}(\alpha_i + 1)\text{个}, \\
&\quad \text{其约数和为 } \sum_{j=0}^{\alpha_i} p_i^j, \\
&\quad \text{根据乘法原理，} f(n) = \prod_{i=1}^s \sum_{j=0}^{\alpha_i} p_i^j \\
\\
&\text{例：} 12 = 2^2 \times 3^1, \\
&\quad f(12) = \{1 + 2 + 4\} \times \{1 + 3\} = 7 \times 4 = 28
\end{aligned}
$$
**公式**：
$$
\begin{aligned}
&\text{若 } i \text{ 是质数，} g[i] = f[i] = i + 1。 \\
&\text{在线性筛中，每个合数 } m \text{ 都是被最小的质因子筛掉的。} \\
&\text{设 } p_j \text{ 是 } m \text{ 的最小质因子，则 } m \text{ 通过 } m = i \times p_j \text{ 筛掉。} \\
&(1) \text{ 若 } i \text{ 能被 } p_j \text{ 整除，则 } p_j \text{ 一定也是 } i \text{ 的最小质因子} \\
&\quad g[i] = p_j^0 + p_j^1 + \cdots + p_j^{\alpha_j}, \quad g[m] = p_j^0 + p_j^1 + \cdots + p_j^{\alpha_j+1} \\
&\quad f[i] = g[i] \times \cdots, \quad f[m] = g[m] \times \cdots \\
&\quad f[m]=f[i]/g[i] \times g[m] \\
&(2) \text{ 若 } i \text{ 不能被 } p_j \text{ 整除，则 } i \text{ 不包含质因子 } p_j。 \\
&\quad g[m] = 1 + p_j \\
&\quad f[m] = g[m] \times f[i]
\end{aligned}
$$

```c++
int p[N],vis[N],cnt;
int g[N],f[N];//g[i]表示i的最小质因子p的1+p^1+p^2+……+p^k,f[i]表示i的约数和
void get_f(int n){
    g[1]=f[1]=1;
    for(int i=2;i<=n;i++){
        if(!vis[i]){
            p[++cnt]=i;
            g[i]=f[i]=i+1;
        }
        for(int j=1;i*p[j]<=n;j++){
            int m=i*p[j];
            vis[m]=1;
            if(i%p[j]==0){
                g[m]=g[i]*p[j]+1;
                f[m]=f[i]/g[i]*g[m];
                break;
            }else{
                g[m]=p[j]+1;
                f[m]=f[i]*g[m];
            }
        }
    }
}
```

## 莫比乌斯函数

**定义**：
$$
\begin{aligned}
&\mu(n) = \begin{cases}
1 & n = 1 \\
0 & n\text{ 含相同质因子} \\
(-1)^s & s\text{ 为 }n\text{ 的不同质因子的个数}
\end{cases} \\
\\
&\text{例：} \mu\{1,6,10,15\} = 1, \mu\{4,8,9,12\} = 0, \mu\{2,3,5,7,30\} = -1
\end{aligned}
$$
**公式**：
$$
\begin{aligned}
&\text{若 } i \text{ 是质数，} mu[i] = -1。 \\
&\text{在线性筛中，每个合数 } m \text{ 都是被最小的质因子筛掉的。} \\
&\text{设 } p_j \text{ 是 } m \text{ 的最小质因子，则 } m \text{ 通过 } m = i \times p_j \text{ 筛掉。} \\
&(1) \text{ 若 } i \text{ 能被 } p_j \text{ 整除，则 } i \text{ 也包含质因子 } p_j。 \\
&\quad mu[m] = 0。 \\
&(2) \text{ 若 } i \text{ 不能被 } p_j \text{ 整除，则 } m \text{ 比 } i \text{ 多一个不同的质因子}p_j \\
&\quad \text{若}mu[i] = -1,\text{则}mu[m] = 1; \\
&\quad \text{若}mu[i] = 1,\text{则}mu[m] = -1; \\
&\quad \text{若}mu[i] = 0,\text{则}mu[m] = 0。 \\
&\quad \text{所以，} mu[m] = -mu[i]。
\end{aligned}
$$

### 筛法求莫比乌斯函数

```c++
const int N=1e5+9;
int p[N],vis[N],cnt;
int mu[N];
void get_mu(int n){
    mu[1]=1;
    for(int i=2;i<=n;i++){
        if(!vis[i]){
            p[++cnt]=i;
            mu[i]=-1;
        }
        for(int j=1;j<=n;j++){
            int m=i*p[j];
            vis[m]=1;
            /*if(i%p[j]==0){
                mu[m]=0;
                break;
            }else{
                mu[m]=-mu[i];
            }*/
            if(i%p==0) break;
            mu[m]=-mu[i];
        }
    }
}
```
