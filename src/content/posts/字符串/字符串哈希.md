## 字符串哈希

**字符串哈希**是一种将字符串映射成一个整数的方法，这个整数被称为字符串的哈希值。

1.  把字符串映射成一个 $p$ 进制数字。
    对于一个长度为 $n$ 的字符串 $s$，
    这样定义 Hash 函数：
    $$h(s) = \sum_{i=1}^n s[i] \times p^{n-i} \pmod{M}$$
    例如，字符串 $abc$，其哈希函数值为 $ap^2 + bp^1 + c$
    即 $97 \times 131^2 + 98 \times 131^1 + 99$

2.  如果两字符串不一样，Hash 函数值却一样，这样的现象称为 **哈希碰撞**。

3.  解决哈希碰撞的方法：
    巧妙设置 $p$ 和 $M$ 的值，保证 $p$ 与 $M$ 互质。
    $p$ 通常取质数 $\boldsymbol{131}$ 或 $\boldsymbol{13331}$，
    $M$ 通常取大整数 $\boldsymbol{2^{64}}$，把哈希函数值 $h$ 定义为 `unsigned long long`（ULL），超过则自动溢出，等价于取模。
    当然也可以直接设置模数手动取模。

```c++
const int prime=131,mod=998244353;

int p[N],h[N];

void init(){
    p[0]=1,h[0]=0;
    for(int i=1;i<=n;i++){
        p[i]=(p[i-1]*prime)%mod;
        h[i]=(h[i-1]*prime+s[i]-'a')%mod;
    }
}

int get(int l,int r){//查询子串[l,r]的哈希值
    return (h[r]-h[l-1]*p[r-l+1]%mod+mod)%mod;
}

//判断两个子串是否相等
bool substr(int l1,int r1,int l2,int r2){
    return get(l1,r1)==get(l2,r2);
}
```
