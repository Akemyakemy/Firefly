## 最小表示法

定义：当字符串S中选定一个位置i满足S[i~n]+S[1~i-1]=T,则T是S的循环同构串。最小表示法是指在所有循环同构串中，字典序最小的。

对于循环串（或环），通常的技巧是复制一倍，破环成链然后扫描。

算法流程：

1. 把字符串复制一倍。
2. 初始化指针i=1,j=2,匹配长度k=0.
3. 比较s[i+k]和s[j+k]是否相等。
4. （1）s[i+k]==s[j+k],则k++
5. （2）s[i+k]>s[j+k],则i=i+k+1
6. （3）s[i+k]<s[j+k],则j=j+k+1
7. 若跳转后两个指针相同，则j++，以确保比较过程中两个字符串不同
8. 重复上述过程，直到比较结束，答案为min(i,j)

```c++
string s;

int get_min(string& s){
    int len=s.size();
    for(int i=1;i<=n;i++) s[n+i]=s[i];
    int i=1,j=2,k=0;
    while(i<=n && j<=n){
        for(k=0;k<n&&s[i+k]==s[j+k];k++);
        s[i+k]>s[j+k]?i=i+k+1:j=j+k+1;
        if(i==j) j++;
    }
    return min(i,j);
}
```
