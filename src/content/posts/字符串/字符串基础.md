# 字符串基础

最常用的操作只有：

| 函数名      | 所属分类 | 常用重载形式                                                 | 参数说明                                                     | 功能描述                                                     | 代码示例及结果                                               |
| ----------- | -------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **substr**  | 查       | `string substr(size_t pos = 0, size_t len = npos) const;`    | `pos`：起始截取位置（默认从 0 开始）`len`：截取长度（默认截取到字符串末尾） | 截取原字符串的一个子串，**不修改原字符串**                   | `s.substr(1, 3); // 返回 "bcd"``s.substr(2); // 返回 "cde"`  |
| **insert**  | 增       | `string& insert(size_t pos, const string& str);`             | `pos`：插入位置`str`：要插入的字符串                         | 在指定位置`pos`插入整个字符串`str`                           | `s.insert(2, "xyz"); // s = "abxyzcde"`                      |
|             |          | `string& insert(size_t pos, size_t n, char c);`              | `pos`：插入位置`n`：字符个数`c`：要插入的字符                | 在指定位置`pos`插入`n`个重复的字符`c`                        | `s.insert(0, 2, '0'); // s = "00abcde"`                      |
|             |          | `iterator insert(iterator p, char c);`                       | `p`：指向插入位置的迭代器`c`：要插入的字符                   | 在迭代器指向的位置插入单个字符`c`                            | `s.insert(s.begin()+1, 'x'); // s = "axbcde"`                |
| **erase**   | 删       | `string& erase(size_t pos = 0, size_t len = npos);`          | `pos`：起始删除位置（默认从 0 开始）`len`：删除长度（默认删除到末尾） | 删除从`pos`开始的`len`个字符                                 | `s.erase(2, 3); // s = "ab"``s.erase(1); // s = "a"`         |
|             |          | `iterator erase(iterator p);`                                | `p`：指向要删除字符的迭代器                                  | 删除迭代器指向的**单个字符**                                 | `s.erase(s.begin()+2); // s = "abde"`                        |
|             |          | `iterator erase(iterator first, iterator last);`             | `first`：起始迭代器`last`：结束迭代器                        | 删除迭代器范围`[first, last)`内的所有字符                    | `s.erase(s.begin()+1, s.end()-1); // s = "ae"`               |
| **find**    | 查       | `size_t find(const string& str, size_t pos = 0) const;`      | `str`：要查找的子串`pos`：起始查找位置（默认从 0 开始）      | 从`pos`开始查找子串`str`**第一次**出现的位置                 | `s.find("cd"); // 返回 2``s.find("cd", 3); // 返回 string::npos` |
|             |          | `size_t find(char c, size_t pos = 0) const;`                 | `c`：要查找的字符`pos`：起始查找位置（默认从 0 开始）        | 从`pos`开始查找字符`c`**第一次**出现的位置                   | `s.find('b'); // 返回 1``s.find('f'); // 返回 string::npos`  |
| **reverse** | 改       | `template<class BidirectionalIterator><br>void reverse(BidirectionalIterator first, BidirectionalIterator last);` | `first`：起始迭代器`last`：结束迭代器                        | 反转迭代器范围`[first, last)`内的字符顺序⚠️ **不是 string 成员函数**，需包含`<algorithm>`头文件 | `reverse(s.begin(), s.end()); // s = "edcba"``reverse(s.begin()+1, s.end()-1); // s = "adcbe"` |

以下为字符串全部操作。

## 查

### 子串与字符获取

| 方法                  | 功能说明                                                     | 示例                                            |
| --------------------- | ------------------------------------------------------------ | ----------------------------------------------- |
| `substr(pos, len)`    | 从位置`pos`开始，截取长度为`len`的子串若`len`省略则截取到末尾 | `string s = "abcde"; s.substr(1, 3); // "bcd"`  |
| `at(pos)`             | 获取位置`pos`的字符，**带边界检查**越界抛出`out_of_range`异常 | `s.at(2); // 'c'`                               |
| `operator[pos]`       | 获取位置`pos`的字符，**无边界检查**越界行为未定义            | `s[0]; // 'a'`                                  |
| `front()` (C++11)     | 获取第一个字符                                               | `s.front(); // 'a'`                             |
| `back()` (C++11)      | 获取最后一个字符                                             | `s.back(); // 'e'`                              |
| `copy(buf, len, pos)` | 将从`pos`开始的`len`个字符复制到`buf`中返回实际复制的字符数  | `char buf[10]; s.copy(buf, 3, 1); // buf="bcd"` |

### 查找操作

所有查找方法成功返回匹配位置（`size_t`类型），失败返回`string::npos`（值为`-1`的无符号整数）。

| 方法                          | 功能说明                                       | 示例                              |
| ----------------------------- | ---------------------------------------------- | --------------------------------- |
| `find(str, pos)`              | 从`pos`开始查找子串`str`第一次出现的位置       | `s.find("cd"); // 2`              |
| `find(c, pos)`                | 从`pos`开始查找字符`c`第一次出现的位置         | `s.find('b'); // 1`               |
| `rfind(str, pos)`             | 从`pos`开始反向查找子串`str`最后一次出现的位置 | `s.rfind("a"); // 0`              |
| `rfind(c, pos)`               | 从`pos`开始反向查找字符`c`最后一次出现的位置   | `s.rfind('e'); // 4`              |
| `find_first_of(str, pos)`     | 查找第一个属于`str`中任意字符的位置            | `s.find_first_of("bdf"); // 1`    |
| `find_last_of(str, pos)`      | 查找最后一个属于`str`中任意字符的位置          | `s.find_last_of("bdf"); // 3`     |
| `find_first_not_of(str, pos)` | 查找第一个不属于`str`中任意字符的位置          | `s.find_first_not_of("ab"); // 2` |
| `find_last_not_of(str, pos)`  | 查找最后一个不属于`str`中任意字符的位置        | `s.find_last_not_of("de"); // 2`  |
| `starts_with(str)` (C++20)    | 判断字符串是否以`str`开头                      | `s.starts_with("ab"); // true`    |
| `ends_with(str)` (C++20)      | 判断字符串是否以`str`结尾                      | `s.ends_with("de"); // true`      |
| `contains(str)` (C++23)       | 判断字符串是否包含子串`str`                    | `s.contains("bc"); // true`       |

### 属性与比较

| 方法                     | 功能说明                                                     | 示例                                      |
| ------------------------ | ------------------------------------------------------------ | ----------------------------------------- |
| `size()`/`length()`      | 返回字符串的字符个数（两者完全等价）                         | `s.size(); // 5`                          |
| `empty()`                | 判断字符串是否为空                                           | `s.empty(); // false`                     |
| `capacity()`             | 返回当前分配的内存容量（可容纳的字符数）                     | `s.capacity(); // 15`（具体值因实现而异） |
| `max_size()`             | 返回字符串理论上能达到的最大长度                             | `s.max_size(); // 约2^31-1`（32 位系统）  |
| `compare(str)`           | 比较两个字符串返回 0 表示相等，<0 表示当前字符串更小，>0 表示更大 | `s.compare("abcde"); // 0`                |
| `compare(pos, len, str)` | 比较当前字符串从`pos`开始的`len`个字符与`str`                | `s.compare(1, 3, "bcd"); // 0`            |
| `c_str()`                | 返回指向以 '\0' 结尾的 C 风格字符串的`const char*`指针       | `const char* p = s.c_str();`              |
| `data()`                 | 返回指向字符数组的`const char*`指针C++11 后与`c_str()`完全等价 | `const char* p = s.data();`               |

## 增

用于向字符串中追加、插入字符或子串。

### 追加操作

| 方法                    | 功能说明                          | 示例                                         |
| ----------------------- | --------------------------------- | -------------------------------------------- |
| `operator+=`            | 追加字符串、字符或 C 风格字符串   | `s += "fg"; // s="abcdefg"`                  |
| `append(str)`           | 追加字符串`str`                   | `s.append("hij"); // s="abcdefghij"`         |
| `append(str, pos, len)` | 追加`str`从`pos`开始的`len`个字符 | `s.append("klmn", 0, 2); // s="abcdefghijk"` |
| `append(n, c)`          | 追加`n`个字符`c`                  | `s.append(3, 'x'); // s="abcdefghijkxxx"`    |
| `push_back(c)` (C++11)  | 追加单个字符`c`                   | `s.push_back('y'); // s="abcdefghijkxxxy"`   |

### 插入操作

| 方法                    | 功能说明                            | 示例                                            |
| ----------------------- | ----------------------------------- | ----------------------------------------------- |
| `insert(pos, str)`      | 在位置`pos`插入字符串`str`          | `s.insert(5, "123"); // 在第5个字符后插入"123"` |
| `insert(pos, str, len)` | 在位置`pos`插入`str`的前`len`个字符 | `s.insert(5, "4567", 2); // 插入"45"`           |
| `insert(pos, n, c)`     | 在位置`pos`插入`n`个字符`c`         | `s.insert(0, 2, '0'); // 开头插入两个'0'`       |
| `insert(iterator, c)`   | 在迭代器指向的位置插入字符`c`       | `s.insert(s.begin(), 'a');`                     |

### 连接操作

| 方法        | 功能说明       | 示例                                                         |
| ----------- | -------------- | ------------------------------------------------------------ |
| `operator+` | 连接两个字符串 | `string s1 = "hello", s2 = "world"; string s3 = s1 + " " + s2;` |

## 删

用于从字符串中删除字符或子串。

| 方法                 | 功能说明                                                     | 示例                                               |
| -------------------- | ------------------------------------------------------------ | -------------------------------------------------- |
| `erase(pos, len)`    | 删除从位置`pos`开始的`len`个字符若`len`省略则删除到末尾      | `s.erase(2, 3); // 删除第2到第4个字符`             |
| `erase(iterator)`    | 删除迭代器指向的单个字符                                     | `s.erase(s.begin()); // 删除第一个字符`            |
| `erase(first, last)` | 删除迭代器`[first, last)`范围内的所有字符                    | `s.erase(s.begin()+1, s.end()-1); // 保留首尾字符` |
| `pop_back()` (C++11) | 删除最后一个字符                                             | `s.pop_back();`                                    |
| `clear()`            | 清空整个字符串，长度变为 0                                   | `s.clear();`                                       |
| `resize(n)`          | 将字符串长度调整为`n`若`n < 当前长度`，则截断末尾字符若`n > 当前长度`，则用 '\0' 填充 | `s.resize(3); // 只保留前3个字符`                  |
| `resize(n, c)`       | 将字符串长度调整为`n`若`n > 当前长度`，则用字符`c`填充       | `s.resize(5, 'a'); // 不足部分用'a'填充`           |

## 改

用于修改字符串中的字符、替换子串或重新赋值。

### 赋值操作

| 方法                    | 功能说明                            | 示例                                          |
| ----------------------- | ----------------------------------- | --------------------------------------------- |
| `operator=`             | 赋值字符串、字符或 C 风格字符串     | `s = "new string";`                           |
| `assign(str)`           | 赋值为字符串`str`                   | `s.assign("hello");`                          |
| `assign(str, pos, len)` | 赋值为`str`从`pos`开始的`len`个字符 | `s.assign("hello world", 0, 5); // s="hello"` |
| `assign(n, c)`          | 赋值为`n`个字符`c`                  | `s.assign(5, 'a'); // s="aaaaa"`              |

### 替换操作

| 方法                            | 功能说明                                           | 示例                                                |
| ------------------------------- | -------------------------------------------------- | --------------------------------------------------- |
| `replace(pos, len, new_str)`    | 将从`pos`开始的`len`个字符替换为`new_str`          | `s.replace(1, 2, "xyz"); // 替换第1-2个字符为"xyz"` |
| `replace(first, last, new_str)` | 将迭代器`[first, last)`范围内的字符替换为`new_str` | `s.replace(s.begin(), s.begin()+3, "abc");`         |
| `operator[pos]`                 | 修改指定位置的字符（无边界检查）                   | `s[0] = 'A';`                                       |
| `at(pos)`                       | 修改指定位置的字符（带边界检查）                   | `s.at(1) = 'B';`                                    |

### 其他修改操作

| 方法                      | 功能说明                                                  | 示例                                         |
| ------------------------- | --------------------------------------------------------- | -------------------------------------------- |
| `swap(str)`               | 交换当前字符串与`str`的内容                               | `string s1 = "a", s2 = "b"; s1.swap(s2);`    |
| `reserve(n)`              | 预留至少能容纳`n`个字符的内存不改变字符串内容，仅优化性能 | `s.reserve(100); // 提前分配100个字符的空间` |
| `shrink_to_fit()` (C++11) | 释放多余的内存，使`capacity()`等于`size()`                | `s.shrink_to_fit();`                         |

### 大小写转换

`tolower(c)`、`toupper(c)`只能将字符进行转换，要将字符串进行转换：

```c++
for (char& c : s) {
    c = toupper(c);
}
```
