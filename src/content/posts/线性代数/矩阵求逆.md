## 矩阵求逆

矩阵求逆一共有两种方法，分别是高斯-约旦消元法$O(n^3)$和费马小定理+矩阵快速幂法$O(n^3logp)$，此处只讨论[高斯-约旦消元法](https://blog.542000.xyz/posts/%E7%BA%BF%E6%80%A7%E4%BB%A3%E6%95%B0/%E9%AB%98%E6%96%AF%E6%B6%88%E5%85%83/)。

![](https://img.542000.xyz/file/算法/1781527835539_屏幕截图_2026-06-15_205014.png)

```c++
bool gauss_jordan(double a[N][N<<1]){
    for(int i=1;i<=n;i++){
        int r=i;
        for(int k=i;k<=n;k++)
            if(fabs(a[k][i])>eps){r=k;break;}
        if(r^i) swap(a[r],a[i]);
        if(fabs(a[i][i])<eps) return 0;
        
        for(int k=1;k<=n;k++){//对角化
            if(k==i) continue;
            double t=a[k][i]/a[i][i];
            for(int j=i;j<=n+1;j++)
                a[k][j]-=t*a[i][j];
        }
        for(int j=1;j<=2*n;j++) a[i][j]/=a[i][i];
    }
    return 1;
}
```
