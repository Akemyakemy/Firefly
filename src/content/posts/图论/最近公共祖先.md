## 最近公共祖先

两个节点的最近公共祖先（Lowest Common Ancestor，LCA）就是这两个点的公共祖先里面，离他们最近的那个。

### [ST表](https://blog.542000.xyz/posts/%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84/st%E8%A1%A8-rmq%E9%97%AE%E9%A2%98/)

构建$O(nlogn)$+查询(logn)

```c++
const int N=5e5+9;
int n,m,s,a,b;
vector<int> e[N];
int dep[N],fa[N][20];

void dfs(int u,int f){//构建ST表
    dep[u]=dep[f]+1;
    fa[u][0]=f;
    for(int i=1;i<20;i++) fa[u][i]=fa[fa[u][i-1]][i-1];
    for(auto v:e[u]) if(v^f) dfs(v,u);
}

int lca(int u,int v){//查询lca
    if(dep[u]<dep[v]) swap(u,v);
    for(int i=19;~i;i--) if(dep[fa[u][i]]>=dep[v]) u=fa[u][i];//将u跳到v同一层
    if(u==v) return v;
    for(int i=19;~i;i--) if(fa[u][i]^fa[v][i]) u=fa[u][i],v=fa[v][i];
    return fa[u][0];
}
```

### Tarjan算法

离线算法，利用[并查集](https://blog.542000.xyz/posts/%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84/%E5%B9%B6%E6%9F%A5%E9%9B%86/)维护祖先节点。

构建$O(n)$+查询$O(q)$

```c++
vector<int> e[N];
vector<pii> query[N];
int fa[N],vis[N],ans[N];

int find(int x){
    return fa[x]^x?fa[x]=find(fa[x]):x;
}

void tarjan(int u){
    vis[u]=1;
    for(auto v:e[u]){//构建
        if(!vis[v]){
            tarjan(v);
            fa[v]=u;
        }
    }
    for(auto q:query[u]){//查询
        int v=q.x,i=q.y;
        if(vis[v]) ans[i]=find(v);
    }
}
```
