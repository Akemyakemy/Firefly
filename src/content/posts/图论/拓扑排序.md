## 拓扑排序

拓扑排序是指在有向图中，将所有顶点按照**出度和入度**排列，使得对于任意一条有向边 uv，u 出现在 v 之前。

时间复杂度：$O(V+E)$

### Kahn算法

BFS算法

```c++
vector<int> e[N]，tp;
int in[N];//入度，表示in[i]表示有多少点可以直接到达i点

bool toposort(){
    queue<int> q;
    for(int i=1;i<=n;i++) if(!in[i]) q.push(i);
    while(q.size()){
        int u=q.front();q.pop();
        tp.push_back(u);
        for(auto v:e[u]){
            if(--in[v]==0) q.push(v);
        }
    }
    return tp.size()==n;//false为有环
}

signed main(){
    cin>>n>>m;
    for(int i=0;i<n;i++){
        cin>>a>>b;
        e[a].push_back(b);
        in[b]++;//建图
    }
    if(toposort()) for(auto u:tp) cout<<u<<" ";
    else puts("-1");
    return 0;
}
```

### DFS算法

算法核心是**变色法**，一路搜一路给点变色，如果有拓扑序，每个节点都会从0->-1->1，经历三次变色。

```c++
vector<int> e[N],tp;
int c[N];//变色数组

bool dfs(int u){
    c[u]=-1;
    for(int v:e[u]){
        if(c[v]<0) return 0;//有环
        else if(!c[v]) if(!dfs(c[v])) return 0;
    }
    c[u]=1;
    tp.push_back(u);
    return 1;
}

bool toposort(){
    memset(c,0,sizeof(c));
    for(int i=1;i<=n;i++)
        if(!c[i]) if(!dfs(i)) return 0;
    reverse(tp.begin(),tp.end());
    return 1;
}
```
