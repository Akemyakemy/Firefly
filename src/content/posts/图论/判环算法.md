## 判环算法

判环算法是指判断一个图是否包含环的算法。

### SPFA算法

通过统计每个顶点的入队次数，若某顶点入队次数超过总顶点数，则判定图中存在环。

$O(nm)$

```c++
bool spfa(int u){
    vis[u]=1;
    for(int i=h[u];~i;i=ne[i]){//链式前向星
        int v=to[i];
        if(d[v]>d[u]+w[i]){
            d[v]=d[u]+w[i];
            pre[v]=u;
            if(vis[v]||spfa(v)) return true;//如果v已经过（找到环）或递归发现负环
        }
    }
    vis[u]=0;
    return false;
}
```

### 拓扑排序

[拓扑排序](https://blog.542000.xyz/posts/%E5%9B%BE%E8%AE%BA/%E6%8B%93%E6%89%91%E6%8E%92%E5%BA%8F/)反复移除入度为 0 的顶点，若最终仍有顶点未被删除，则判定图中存在环。

最后直接遍历节点，找到环即可。

### Floyd算法

Floyd判环就是快慢指针龟兔算法，用于检测链表或确定性迭代序列的环。在图论中不通用。
