## 剪枝

剪枝是指在搜索过程中，通过一些条件的判断，避免搜索一些不可能的路径，从而提高搜索效率。

搜索中的`A*算法和IDA*算法`均为启发式搜索算法，他们的估价函数就是综合了以下的最优性剪枝和可行性剪枝的成果。

### 记忆化搜索

在搜索过程中，记录已经搜索过的节点，避免重复搜索，是一种**动态规划算法**。一般情况下可以认为是最优剪枝方法，效率最高。博弈论中常用。

示例：**质数博弈**

给出一个数n，每次A先手，B后手。

- A可以将数变为`[n,2*n-1]`中的任何一个数
- B每次只能让n除以n的质因数

A希望回合数越大越好，B希望回合数越小越好，假设A和B都足够聪明，输出n变为1时的最大回合数。

题解：预处理所有仅有2和3作为质因数的数即可。

```c++
#include<bits/stdc+.h>
using namespace std;
#define int long long
const int N=2e3+9;
const int inf=LLONG_MAX;

int a[N],idx=1;
map<int,int> mp;
void init(){
    a[0]=1;
    for(int i=1;;i++){
        int tmp=a[i-1]<<1;
        if(tmp>inf || tmp<0) break;//越界
        a[i]=tmp;
        idx++;
    }
    for(int i=0;i<62;i++){
        int tmp=a[i];
        while(tmp*3<inf && tmp*3>0){
            tmp*=3;
            a[idx++]=tmp;
        }
    }
    sort(a,a+idx);
    mp[0]=0;mp[1]=0;mp[2]=1;mp[3]=2;mp[4]=2;
}

int dfs(int n){
    if(mp.count(n)) return mp[n];
    int ans=0;
    int p=lower_bound(a,a+idx,n)-a;
    int j=0;
    while(a[p+j]<2*n && p+j<idx){
        if(a[p+j]%3==0) ans=max(ans,dfs(a[p+j]/3));
        else ans=max(ans,dfs(a[p+j]/2));
        j++;
    }
    return mp[n]=ans;
}

signed main(){
    init();
    int n;cin>>n;
    cout<<dfs(n)<<endl;
    return 0;
}
```

### 最优性剪枝

在dfs中，搜索到一条路径后产生一个答案，此后的搜索都先判断是否会大于这个答案，若大于则剪枝。若找到新的路径则更新答案。

```c++
#define pii pair<int,int>
#define v first
#define w second
vector<pii> e[N];

int ans=inf;
bool dfs(int u,int res){
    if(u==t){
        if(res<ans) ans=res;
        return true;
    }
    for(auto ed:e[u]){
        int v=ed.v,w=ed.w;
        if(res+w>ans) return false;//不优则剪枝
        dfs(v,res+w);
    }
}
```

bfs中也有相应的剪枝方法，原理相同，不多赘述。

有些时候排序会影响答案的效率，可以升序或降序排列再进行搜索，这也是最优性剪枝。

### 可行性剪枝

直接判断某条路径是否可行，如果不行则剪枝。

如该路径不能打到目标终点，直接剪枝。思路与代码实现和最优性剪枝一致。

### 等效性剪枝

当判断该路径与之前的错误路径或有效路径等效时，直接剪枝。

如当前节点到某两个节点的距离一致，两个节点的后续节点及其距离也完全一致，可以剪枝一条路径。思路与代码实现和最优性剪枝一致。

### 小木棍剪枝

综合性的剪枝。

原题连接：[小木棍](https://www.luogu.com.cn/problem/P1120)

```c++
#include<bits/stdc++.h>
using namespace std;

const int N=100;

int n,len,cnt;
int a[N],used[N];

void dfs(int u,int cur,int start){
    if(u>cnt){
        cout<<len<<endl;
        exit(0);
    }
    if(cur==len){
        dfs(u+1,0,1);
        return;
    }
    for(int i=start;i<=n;i++){
        if(used[i] || cur+a[i]>len) continue;
        used[i]=1;
        dfs(u,cur+a[i],i+1);
        used[i]=0;

        if(cur==0) return;//拼接第一个失败回溯
        if(cur+a[i]==len) return;//拼接最后一个失败回溯
        while(i<n && a[i]==a[i+1]) i++;//等效性剪枝
    }
}

signed main(){
    cin.tie(nullptr)->sync_with_stdio(false);
    cin>>n;
    int sum=0;
    for(int i=1;i<=n;i++) cin>>a[i],sum+=a[i];
    sort(a+1,a+n+1,greater<int>());//优化搜索顺序

    for(len=a[1];;len++){
        if(sum%len) continue;
        cnt=sum/len;
        dfs(1,0,1);//第一次拼好即答案
    }
    return 0;
}
```
