## 二分查找

​	时间复杂度 $O(logn)$ .

### STL二分

​	主要有两个函数：

```c++
lower_bound//查找第一个大于等于的数
upper_bound//查找第一个大于的数
```

​	返回值是一个迭代器，写法根据数据结构类型的不同有所不同，下面以`lower_bound`为例：

| 数据结构          | lower_bound 标准写法                     | 返回值类型     | 找到 (≥目标)          | 未找到 (全小于目标) |
| ----------------- | ---------------------------------------- | -------------- | --------------------- | ------------------- |
| 静态数组          | `lower_bound(a, a+n, val)`               | 原生指针       | 指向首个≥val 元素     | 返回 `a+n`          |
| 有序 vector/array | `lower_bound(v.begin(),v.end(),val)`     | 随机访问迭代器 | 指向匹配元素          | 返回`end()`         |
| 有序 deque        | `lower_bound(dq.begin(),dq.end(),val)`   | 随机访问迭代器 | 指向匹配元素          | 返回`end()`         |
| list              | `lower_bound(lst.begin(),lst.end(),val)` | 双向迭代器     | 指向匹配元素          | 返回`end()`         |
| set               | `s.lower_bound(val)`                     | 双向迭代器     | 指向首个≥val 元素     | 返回`end()`         |
| multiset          | `ms.lower_bound(val)`                    | 双向迭代器     | 指向第一个匹配元素    | 返回`end()`         |
| map               | `mp.lower_bound(key)`                    | 双向迭代器     | 指向对应 key 键值对   | 返回`end()`         |
| multimap          | `mmp.lower_bound(key)`                   | 双向迭代器     | 指向首个同 key 键值对 | 返回`end()`         |

### 整数二分

​	整数二分的板子我推荐下面这个：

```c++
vector<int> a(n);//假设a是一个base-1的升序排序数列
int binary_search(int m){//查找最后一个小于m的数
    int l=0,r=n+1;//l和r设置在界外
    while(l+1<r){
        int mid=(l+r)>>1;
        if(a[mid] >= m) r=mid;
        else l=mid;
    }
    return l;
}
```

#### 关于(l+1 < r)的设置

可以根据题目要求灵活调整，比如上述板子，如果改成查找第一个大于等于m的数，可以直接改成输出r。
