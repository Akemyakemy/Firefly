## 普通线段树

线段树是基于**分治**思想的二叉树，用于维护区间信息。

修改和查询时间复杂度 $O(logn)$ .

![](https://img.542000.xyz/file/算法/1780139105957_屏幕截图_2026-05-30_190431.png)

### 缺省源

```c++
//p是父节点
#define lc p<<1    //二叉树的左子节点，编号是父节点的两倍
#define rc p<<1|1  //右子节点，左节点编号+1
const int N=5e5+9; //假设区间长度为5e5
```

#### 节点数组tr[]

此处假设维护区间和。

三个属性：$l,r,sum$ .

$l,r$ 存区间的左右端点，$sum$ 存区间和。

```c++
struct node{
    int l,r,sum;
}tr[N<<2];//左移两位，开4倍空间
```

### 递归建树

```c++
void build(int p,int l,int r){
    tr[p]={l,r,w[l]};//w是原数组
    if(l==r) return;//是叶子节点则返回
    int m=l+r>>1;//不是叶子节点则分治递归为两个区间
    build(lc,l,m);
    build(rc,m+1,r);
    tr[p].sum=tr[lc].sum+tr[rc].sum;
}
```

### 点修改

```c++
void update(int p,int x,int y){//x是点，y是增量
    if(tr[p].l==x && tr[p].r==x){
        tr[p].sum+=y;
        return ;
    }
    
    int m=tr[p].l+tr[p].r>>1;//分治递归
    if(x<=m) update(lc,x,y);
    if(x>m) update(rc,x,y);
    tr[p].sum=tr[lc].sum+tr[rc].sum;
}
```

### 区间查询

```c++
int query(int p,int x,int y){//x,y是区间的左右端点
    if(x<=tr[p].l && tr[p].r<=y) return tr[p].sum;//若覆盖则直接返回
    int m=tr[p].l+tr[p].r>>1;
    int sum=0;
    if(x<=m) sum+=query(lc,x,y);
    if(y>m) sum+=query(rc,x,y);
    return sum;
}
```
