## 单调栈

这里单调栈维护递增序列，找右侧第一个比当前元素小的元素的下标。

左侧更大，单调递减，比当前小，全部提出。

```c++
int n;
int a[n];
vector<int> res(n+2,n);
int stk[n+2],top=0;//静态数组模拟栈，更加高效
//stk存原数组下标，top为stk大小
for(int i=1;i<=n;i++){
    //当stk中有元素且该元素比a[i]大时
    while(top && a[i]<a[stk[top]]){
        res[stk[top]]=i;//stk[top]对应的元素右侧第一个比它小的元素就是a[i]
        top--;
    }
    stk[top++]=i;
}
```
