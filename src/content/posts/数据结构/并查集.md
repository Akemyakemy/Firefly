## 并查集

定义：并查集是一种用于处理动态连接和查询的树状结构。

### 连通块

定义：连通块是指在并查集中，所有节点通过连接关系连接起来的子图。

### 父节点

```c++
int fa[N];
void init(){
    iota(fa+1,fa+n+1,1);//初始化所有节点的父节点为自己
}
```

### 路径压缩

```c++
int find(int x){//记忆化的形式将所有该连通块的子节点连在父节点下方，极大减小查询时间
    return x^fa[x]?fa[x]=find(fa[x]):x;
}
```

### 节点合并

```c++
void unite(int x,int y){
    int  rx=find(x),ry=find(y);
    fa[rx]=ry;
}
```
