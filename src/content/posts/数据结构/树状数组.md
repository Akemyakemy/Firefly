## 树状数组

又叫做**芬威克树**，是一种支持**单点修改**和**区间查询**的，代码量小的数据结构。时间复杂度为 $O(nlogn)$ ,修改与查询 $O(logn)$ .

![](https://img.542000.xyz/file/算法/1780139277961_屏幕截图_2026-05-30_190742.png)

### 缺省源

```c++
#define lb(x) (x)&(-x)
const int N=5e5+9;
```

上面的$lb(x)$指的是$lowbit(x)$.定义为提取$x$的低位2次幂。即二进制第一位1即后面的0组成的数。

如：$20(10100) $ & $ -20(01100) == 8(100)$ 

利用这个特性可以将原本的数组建立成上图右边的数据结构形式。

### 构造s数组

```c++
int s[N],a[N];
signed main(){
    cin>>n;//n原数组大小
    for(int i=1;i<=n;i++){
        cin>>a[i];
        change(i,a[i]);//每次输入调用修改函数即可
    }
}
```

### 修改

修改分为**点修改**和**区间修改**。

#### 点修

```c++
void change(int x,int y){
    while(x<=n) s[x]+=y,x+=lb(x);//将数据汇总到二进制的上一级
}
```

#### 区修

树状数组存储**差分**。

```c++
void change(int x,int y){...};//change函数不变
signed main(){
    int l,r;//区间的左右端点
    change(l,y);change(r+1,-y);//差分的思想
}
```

### 查询

查询同理。

#### 点查

只能在**差分树状数组**中实现，本质为**前缀和**。

```c++
int query(int x){
    int t=0;
    while(x) t+=s[x],x-=lb(x);//向前查
    return t;
}
```

#### 区查

##### 点修的区查

```c++
int qry(int l,int r){//前缀和思想
    return query(r)-query(l-1);
}
```

##### 区修的区查

区修为差分数组，这时需要对公式进行推导。

1到r的区间和：
$$
\begin{aligned}
\sum_{i=1}^r a[i] &= \sum_{i=1}^r \sum_{j=1}^i d[i] \\
&= \sum_{i=1}^r d[i] \times (r-i+1) \\
&= r\times \sum_{i=1}^r d[i]-\sum_{i=1}^r d[i] \times (i-1)
\end{aligned}
$$
因此我们需要维护$s1$和$s2$两个树状数组来求区间和。

```c++
int s1[N],s2[N];//s1维护d[i],s2维护d[i]*(i-1)

long long query(long long *s,long long x){
    long long t=0;
    while(x) t+=s[x],x-=lb(x);
    return t;
}

int qry(int l,int r){
    return query(s1,r)*y-query(s2,r)
        -(query(s1,l-1)*(l-1)-query(s2,l-1));
}
```
