## 前缀和

前缀和和差分都是基础算法，此处就简单讲一下一维普通数组情况下的使用。

原数组：`a[n]:base-1`

```c++
int b[n];b[0]=0;
for(int i=1;i<=n;i++) b[i]=b[i-1]+a[i];
```

## 差分

对区间整体修改时，如`[l,r]`中所有数`+y`.

```c++
int d[n];d[0]=0;
for(int i=1;i<=n;i++) d[i]=a[i]-a[i-1];//d[1]=a[1]
cin>>l>>r>>y;
d[l]+=y;
if(r<n) d[r+1]-=y;//防止数组越界
```

求修改后的原数组：

```c++
int b[n];
for(int i=1;i<=n;i++) b[i]=b[i-1]+d[i];
```
