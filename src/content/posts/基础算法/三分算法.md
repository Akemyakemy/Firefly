## 三分算法

二分法可以用于近似求出函数的零点．如果需要求出单峰函数的极值点，通常需要使用三分法（ternary search）。

### 三分查找

以下以$y=-x^2+4*x$为例，$f(2)=4$是最大值。

```c++
const double eps=1e-6;

double f(double x){return -x*x+4*x;}

double ternary_search(double l,double r){
    while(r-l>eps){
        double mid1=l+(r-l)/3,mid2=r-(r-l)/3;
        if(f(mid1)>f(mid2)) r=mid2;
        else l=mid1;
    }
    return (l+r>>1);//返回中点
}
```

#### 黄金分割法

![](https://img.542000.xyz/file/算法/1781765951632_屏幕截图_2026-06-18_145808.png)

```c++
const double phi=(1+sqrt(5))/2;//≈0.618
const double eps=1e-6;

double f(double x){return -x*x+4*x;}

double golden_search(double l,double r){
    double m1=l+(r-l)*phi,m2=r-(r-l)*phi;
    double f1=f(m1),f2=f(m2);
    while(r-l>eps){
        if(f1<f2){
            l=f1;
            m1=m2;
            f1=f2;
            m2=r-(r-l)*phi;
            f2=f(m2);
        }else{
            r=f2;
            m2=m1;
            f2=f1;
            m1=l+(r-l)*phi;
            f1=f(m1);
        }
        return (l+r>>1);//返回中点
    }
```
