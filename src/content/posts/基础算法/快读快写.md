## 快读快写

在部分问题中需要频繁读输入和写输出，这需要使用快读快写算法优化。

### 缺省源

```c++
#define gc getchar
#define pc putchar
```

### 快读

```c++
inline int read(){//数字快读
    int sum=0,d=1;
    char c=gc();
    while(c<'0'||c>'9'){
        if(c=='-')d=-1;
        c=gc();
    }
    while(c>='0'&&c<='9'){
        sum=sum*10+c-'0';
        c=gc();
    }
    return sum*d;
}

inline string sread(){//字符串快读
    string str;
    char c = gc();// 跳过前导空白符（空格、换行、制表符）
    while (c == ' ' || c == '\n' || c == '\t') c = gc();// 读取非空白字符，直到遇到空白符或EOF
    while (c != ' ' && c != '\n' && c != '\t' && c != EOF) {
        str += c;
        c = gc();
    }
    return str;
}
```

### 快写

```c++
inline void write(int x){
	if(x<0) pc('-'),x=-x;
	if(x<10) pc(x+'0');
	else write(x/10),pc(x%10+'0');
}
```
